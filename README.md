# Sumi Night

A charcoal and ivory theme for Omarchy 4, with vermilion accents and four 4K ink-wash wallpapers.

![Sumi Night desktop preview](preview.png?v=4e23a0a)

```sh
omarchy theme install https://github.com/erikrjohansson/omarchy-sumi-night-theme.git
```

## Updating

To get new wallpapers and fixes, update your installed themes, then apply Sumi Night again so Omarchy picks up the new files:

```sh
omarchy theme update
omarchy theme set sumi-night
```

## Removing

Switch to another theme first (for example with `omarchy theme switcher`), then remove Sumi Night:

```sh
omarchy theme remove sumi-night
```

## Wallpapers

Plum branch (default), ensō, ridges and koi. Cycle through them from the Omarchy menu under Style → Background.
